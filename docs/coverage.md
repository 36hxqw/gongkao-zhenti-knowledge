## 三、已知缺口与原因

### 1. 无答案的 26 套行测卷

- **广东 2004–2021 行测（24 套）**：原「答案及解析」PDF 为整页扫描图像，无文字层；Windows OCR 实测对「故正确答案为 X」中的字母识别率仅约 60–70%，会产生错误答案，故**不写入**，统一标 `ans: null`。
- **国考 2002 B 卷**（113 题）：答案 PDF 同为扫描件。
- **国考 2021 副省级**（135 题）：解析 PDF 为图片版（全文文字层仅 600 余字）。
- 处理方式：这些卷的题目、考点标注、命题规律统计**照常可用**；问到答案时明确说明「原卷答案未提取，请对照原卷」，并可用同考点其他年份的原题替代举例。

### 2. 未收录的试卷（PDF 无文字层，题目本身抽不出）

| 试卷 | 原因 |
|---|---|
| 国考 2023 副省级、2023 地市级 行测 | 题目 PDF 为扫描图像 |
| 湖北 2021、2022 行测 | 题目与解析 PDF 均为扫描图像 |
| 广东 2021 县级、2022–2025 行政执法 行测 | 题目 PDF 为扫描图像（行政执法 2022/2023 的解析可读，但缺题干） |
| 广东 2008（部分） | 原 PDF 中间若干页为图片，题目缺失较多（仅收录 28 题） |

### 3. 抽取噪声

- 2026 年「网友回忆版」卷（国考地市级、广东）版式为双栏混排，少量题目 stem 中混入选项碎片；已在 docs/data-spec.md 说明，可按 `num` 对照 `references/juan/` 原卷。
- 图形推理题选项为图片，题干为通用问法，`fig=true`（全库 271 条，v1.7 修正 59 条「题干只剩 A B C D / opts 为空」的图选项题）。
- **题干质量标记 `stem_flag`**（v1.7 新增，只标记不删题）：全库 **136 条**——`short` 136、`watermark` 0、`contaminated` 0、`missing_opts` 0（v1.7.1 修完 26 条水印/残句/选项碎片后其余三类归零）；检索显示 `⚠ 题干可能不完整（原因）`，组卷默认排除（`--allow-flagged` 放开）。
- 极少数题目（<0.3%）因原 PDF 分栏/公式出现文字粘连，输出时应换同考点其他题举例。

### 4. 申论答案覆盖

- 419 题中 **287 题有参考答案**，**132 题见原卷**：其中 122 条 `ans_note="答案无法可靠对齐，见本卷「参考答案原文」"`（卷内无问题级标记，或答案块数 ≠ 小题数），10 条 `ans_note="原卷未提供可提取的参考答案"`（原卷确实没有）。
- 卷文件层面：**93 套**有「三、参考答案（按小题）」+「四、参考答案原文」；**11 套**只有「四、参考答案原文」（小题级答案无法可靠对齐）；**2 套**两者皆无（国考 2000 统一卷、湖北 2024 县乡）。「三」里写「见本卷参考答案原文」的小题，按只有原文处理。
- **答案清洗（v1.7）**：剔除广告水印 **7 条**、题干回声 **2 条**；`GD-2018-ty-S01` 的答案在 v1.7.1 已按原卷恢复，因此「有参考答案」现为 **287**（不再是清洗后的 286）。
- 申论 `ans` 只作“参考要点提示”，不得直接用检索片段当答案发布；输出前回 `references/shenlun/<卷>.md` 取原文。

### 5. 年份口径

- 国考 2000–2004 含 A/B 卷；2005 含（一）（二）卷；2015 起分副省级/地市级；2022 起增设行政执法卷；2025 起常识判断中「政治理论」单列。
- 广东：2004–2005 分上/下半年；2013 分一/三卷；2014–2016 分县级/乡镇；2018 起县级乡镇合卷；2024 起改为一/二/三卷（三卷为行政执法）。
- 湖北：2009–2020 多为多省联考湖北卷；2019 另含选调生卷。
