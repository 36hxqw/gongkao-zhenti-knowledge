## 三、已知缺口与原因

### 1. 无答案的 26 套行测卷

- **广东 2004–2021 行测（22 套）**：原「答案及解析」PDF 为整页扫描图像，无文字层；Windows OCR 实测对「故正确答案为 X」中的字母识别率仅约 60–70%，会产生错误答案，故**不写入**，统一标 ns: null。
- **国考 2002 B 卷**：答案 PDF 同为扫描件。
- **国考 2021 副省级**：解析 PDF 为图片版（全文文字层仅 600 余字）。
- 处理方式：这些卷的题目、考点标注、命题规律统计**照常可用**；问到答案时明确说明「原卷答案未提取，请对照原卷」，并可用同考点其他年份的原题替代举例。

### 2. 未收录的试卷（PDF 无文字层，题目本身抽不出）

| 试卷 | 原因 |
|---|---|
| 国考 2023 副省级、2023 地市级 行测 | 题目 PDF 为扫描图像 |
| 湖北 2021、2022 行测 | 题目与解析 PDF 均为扫描图像 |
| 广东 2021 县级、2022–2025 行政执法 行测 | 题目 PDF 为扫描图像（行政执法 2022/2023 的解析可读，但缺题干） |
| 广东 2008（部分） | 原 PDF 中间若干页为图片，题目缺失较多（仅收录 28 题） |

### 4. 年份口径

- 国考 2000–2004 含 A/B 卷；2005 含（一）（二）卷；2015 起分副省级/地市级；2022 起增设行政执法卷；2025 起常识判断中「政治理论」单列。
- 广东：2004–2005 分上/下半年；2013 分一/三卷；2014–2016 分县级/乡镇；2018 起县级乡镇合卷；2024 起改为一/二/三卷（三卷为行政执法）。
- 湖北：2009–2020 多为多省联考湖北卷；2019 另含选调生卷。
