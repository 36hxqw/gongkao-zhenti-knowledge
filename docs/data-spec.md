# 数据说明与字段规范

本库所有检索能力都建立在两份 JSONL 上，加一份 TSV 检索索引。文件均为 UTF-8，一行一条 JSON，可直接 `grep` / `jq` / Python 读取。

## 一、文件清单

| 文件 | 内容 | 体量 |
|---|---|---|
| `data/xingce.jsonl` | 行测题目（1 行 1 题） | 11 393 行 |
| `data/shenlun.jsonl` | 申论小题（1 行 1 小题，含材料） | 419 行 |
| `data/search-index.tsv` | 检索索引（1 行 1 题，短行，适合 grep） | 11 813 行（11 812 条 + 首行注释） |
| `data/stats.json` | 全库统计 | — |

## 二、`data/xingce.jsonl` 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 唯一编号，`省-年-卷别-X题号`，如 `GK-2024-fs-X112`、`GD-2023-xj-X045` |
| `prov` | string | `国考` / `广东` / `湖北` |
| `year` | int | 考试年份 |
| `vol` | string | 卷别：`副省级`/`地市级`/`行政执法`/`省级`/`统一卷`/`县级`/`乡镇`/`县乡`/`省市`/`A卷`/`B卷`/`一卷`/`二卷`/`三卷`/`选调`/`思维能力测验`/`综合行政能力测验`/`公安` |
| `num` | int | 原卷题号 |
| `module` | string | 模块：资料分析 / 数量关系 / 言语理解 / 判断推理 / 常识判断 |
| `type` | string | 题型名（对齐花生十三）：如 `基期量计算`、`逻辑填空`、`图形推理`、`政治常识` |
| `code` | string | 考点编码，见 `docs/kaodian-taxonomy.md` |
| `sub` | string | 三级子考点（如「两期比重差」「最不利构造」「翻译推理」），可直接用 `--sub` 检索 |
| `stem` | string | 题干（已去除选项；资料分析题的材料见 `ctx`） |
| `opts` | object | 选项，键为 `A/B/C/D`；图形题为空对象 `{}` |
| `ans` | string\|null | 正确答案字母；`null` 表示原卷为扫描版未提取到答案，**或**原卷答案字母不在本题选项键内（此时另有 `ans_note` 说明） |
| `ans_note` | string\|null | 答案不可用的原因说明。当前 15 条为 `"原卷答案与选项不匹配"`（`ans` 已置 `null`）；正常题为 `null` |
| `expl` | string | 原解析文本（节选，最长约 4000 字）；可能为空 |
| `ctx` | string | 资料分析的给定材料 / 篇章阅读的材料原文 |
| `kw` | array | 关键词标签（领域词典 + 高频 bigram），最长 12 个，用于快速过滤 |
| `fig` | bool | `true` 表示图形题（选项为图片，图见原卷） |
| `img` | string\|null | 本题配图文件名（`<id>.jpg`），按题区自动裁切；无图则 `null` |
| `mat_img` | string\|null | 材料图文件名（`<首题id>-m.jpg`）：仅当材料是**表格/图表**时生成；同一材料组的非首题继承组首题的文件名 |
| `img_p2` | string\|null | 题目跨页时的第二页续裁图（`<id>-p2.jpg`） |
| `canonical` | string | 同题主记录 id（同题折叠用）；主记录自身 `canonical == id` |
| `dup_n` | int | 该题的同题变体总数（含自身）；`1` 表示无变体 |
| `diff` | int | 难度 1–5（1 易 – 5 难），模块内等频；`diff_raw` 为分档前的原始加权分 |
| `src` | string | 来源文件名（题目 PDF \| 答案 PDF），便于溯源核对 |

> 配图口径：题目图 = 题号行到本题选项块结束（含选项是图片的情况，不会再截断）；
> 材料图只为「表格/图表」类材料生成——**纯文字材料不裁图**，其文本已在 `ctx` 字段里；
> 同一材料组只在首题给图，避免重复展示。

## 三、`data/shenlun.jsonl` 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | `省-年-卷别-S小题号`，如 `GK-2024-fs-S01` |
| `prov` / `year` / `vol` | — | 同上 |
| `paper` | string | 试卷编号，同一套卷的多道小题共享 |
| `no` | string | 原卷题号（如"一""问题三""1"） |
| `module` | string | 固定 `申论` |
| `type` | string | `单一题（归纳概括）`/`综合分析题`/`提出对策题`/`公文写作题`/`大作文` |
| `code` | string | `SN-DY`/`SN-ZH`/`SN-DC`/`SN-GW`/`SN-DZW` |
| `sub` | string | 三级子考点（如「概括问题」「词句理解」「事务性公文」） |
| `stem` | string | 题干 + 作答要求（分值、字数限制） |
| `ans` | string\|null | **参考要点提示**（不是标准答案，见 §5.3）；`null` 表示答案不可用，此时 `ans_note` 说明原因 |
| `ans_note` | string\|null | `ans` 不可用的原因：`"答案无法可靠对齐，见本卷「参考答案原文」"`（122 条，卷内无问题级标记或答案块数 ≠ 小题数）或 `"原卷未提供可提取的参考答案"`（10 条） |
| `paper_answer` | string | 整卷参考答案原文（摘自原卷解析）；同一套卷的多道小题共享 |
| `material` | string | 本题所属申论材料全文（同学同卷的几道小题重复存放，便于单独使用） |
| `theme` | array | 主题标签 1–3 个（基层治理 / 乡村振兴 / 科技创新 …，共 15 类） |
| `diff` | int | 难度 1–5（同 xingce） |
| `kw` | array | 关键词标签 |
| `src` | string | 来源文件名 |

> 申论答案的三种卷面形态（决定你该去哪里取答案）：
> ① 有「三、参考答案（按小题）」→ 93 套，可逐小题对应；
> ② 只有「四、参考答案原文」→ 11 套，小题级对齐不可靠，只能引用整卷原文；
> ③ 两者皆无 → 2 套（国考 2000 统一卷、湖北 2024 县乡），按「该题答案不可用，见原卷」表述。

## 四、`data/search-index.tsv` 字段

`#id	year	prov	vol	module	type	kw	stem60`，制表符分隔，首行是注释。`kw` 用空格连接，`stem60` 是题干前 60 字（已去换行）。用于「无 Python 环境」时的文本检索：先在此文件搜关键词拿 `id`，再回 JSONL 取整条。

## 四点五、配图

`references/images/<题目ID>.jpg`：按题号锚点自动裁切的题区截图（150dpi，最长边 820px，JPEG q62，平均 12KB）。覆盖图形推理题与「材料为图表」的资料分析题——这两类题的文字层里没有图，必须看图讲解。共 3 536 张，约 28MB。Markdown 中原生引用；程序里按 `references/images/{id}.jpg` 是否存在判断。

## 五、数据口径

### 5.1 答案来源

只取原卷/原解析中明确写出的「正确答案 X / 故正确答案为 X / 故选 X」；多条解析给出不同答案时取首个。不做人工改判、不推测。

### 5.2 答案置空规则（`ans ∉ opts.keys()`）

**规则**：`ans` 必须落在该题的 `opts` 键集合内。若原卷给出的答案字母不在选项键内（典型来源：扫描版选项被裁掉一部分、判断题卷只有 A/B 两个选项而答案写 C/D），则：

1. `ans` 置为 `null`（**不保留**那个越界字母）；
2. 写入 `ans_note = "原卷答案与选项不匹配"`；
3. 检索与组卷把它当作「无答案」处理（`paper.py` 默认过滤，`search.py` 显示"暂缺"）。

当前命中 15 条（含 5 条判断题），例如 `GK-2002-a-X036`（opts 为 A/B/C）、`HB-2011-ty-X014`（opts 为 A/B/D）。

**两条禁令**：

- **不得**把越界字母当成答案输出；
- **不得**为它编造"口径"解释（如"判断题按对/错给 A/D"、"选项被裁所以用 A/B"）。越界就是缺失，统一表述为**"该题答案不可用，见原卷"**。

**例外**：`opts` 为空的图形/图选项题（全库 513 条）不适用——它们的选项本身是图片，答案是原卷给出的字母，照常输出并提示看图。

### 5.3 申论 `ans` 的定位：参考要点，不是答案

- `ans` 是**"参考要点提示"**，来自原卷解析的要点摘录；它脱离材料与分值，**不能直接当答案发布**。
- 引用检索结果（`--kw` / `--kaodian`）时，若命中申论题，**必须**回 `references/shenlun/<省>-<年>-<卷别>.md`：
  - 有「三、参考答案（按小题）」→ 按小题取；
  - 只有「四、参考答案原文」→ 引原文并注明"整卷参考答案原文，小题级对齐不可靠"；
  - 两者皆无 → "该题答案不可用，见原卷"。
- `ans` 为空或带 `ans_note` → 一律"该题答案不可用，见原卷"，**不得推测、不得用同卷其他小题顶替、不得用生成内容冒充原卷答案**。
- 申论答案本身是"采分点导向、非唯一标准答案"，输出时按要点分层并注明这一点。

### 5.4 题干清洗

去除页眉页脚（`第 X 页 共 Y 页`）、重复卷名；合并被字库拆开的选项标记（如 `B`+`.①③`→`B.①③`）。

### 5.5 选项顺序

多栏排版的原卷按字母还原为 A/B/C/D，不按视觉位置。

### 5.6 图表题

图形推理、资料分析的图表本身是图片，文本层只有题干与答案；此类题 `fig=true`，题干标注"图形题，图见原卷"。**公式按材料自算**：原 PDF 的公式常抽取不全，解析里的残缺算式不可照搬。

### 5.7 完整性

极小比例题目（<0.3%）因原 PDF 分栏/公式出现文字粘连，`stem` 中可能混入选项碎片；输出时如发现明显异常，换同考点其他题举例。

### 5.8 同题重复

同一题会在国考三卷、跨年、联考各省重复出现。数据保留每条原始记录（便于按卷核对），用 `canonical` 标记主记录；检索默认只出主记录，`--all-variants` 展开。全库 1 139 条为同题变体（行测 11 393 → 折叠后 10 254）。

### 5.9 答案缺失

26 套卷（广东 2004–2021 行测、国考 2002 B 卷、国考 2021 副省级）的原答案 PDF 是扫描件、无文字层，`ans` 为 `null`，输出时必须如实说明，**不得编造答案**。逐卷数字见 `docs/coverage.md`。

## 六、复现与再生成

`tools/pipeline/` 保留了从原始 PDF 到本库的完整流水线（PyMuPDF 文本抽取 → 题目结构化 → 考点分类 → 索引与文档生成）。重新采集时：

```bash
python tools/pipeline/survey.py        # 先探测 PDF 文本层可用性
python tools/pipeline/build_xingce.py  # 行测抽取
python tools/pipeline/build_shenlun.py # 申论抽取
python tools/pipeline/finalize.py      # 生成 data/
python tools/pipeline/gen_docs.py      # 生成 references/
```

流水线不依赖公网，只依赖 `pymupdf`。

> 注：`references/00-index.md` 的「按考点检索」表由 `gen_docs.py` 生成，题量为**同题折叠后**口径，首次数据行上方有口径脚注；全量口径以 `docs/kaodian-taxonomy.md` 与 `scripts/search.py --list-kaodian` 为准。
