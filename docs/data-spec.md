## 四、`data/search-index.tsv` 字段

`#id	year	prov	vol	module	type	kw	stem60`，制表符分隔，首行是注释。`kw` 用空格连接，`stem60` 是题干前 60 字（已去换行）。用于「无 Python 环境」时的文本检索：先在此文件搜关键词拿 `id`，再回 JSONL 取整条。

## 四点五、配图

`references/images/<题目ID>.jpg`：按题号锚点自动裁切的题区截图（150dpi，最长边 820px，JPEG q62，平均约 16KB）。覆盖图形推理题与「材料为图表」的资料分析题——这两类题的文字层里没有图，必须看图讲解。共 **3 536 个文件、约 55.4MB**：题目图 3 148 + 材料图 225（表格/图表独立裁切，同一材料组共享同一张，故 `mat_img` 字段有 **1 455 条**记录引用）+ 跨页续图 163。Markdown 中原生引用；程序里按 `references/images/{id}.jpg` 是否存在判断。

## 五、数据口径

### 5.1 答案来源

只取原卷/原解析中明确写出的「正确答案 X / 故正确答案为 X / 故选 X」；多条解析给出不同答案时取首个。不做人工改判、不推测。

### 5.2 答案置空规则（`ans ∉ opts.keys()`）

**规则**：`ans` 必须落在该题的 `opts` 键集合内。若原卷给出的答案字母不在选项键内（典型来源：选项被裁掉一部分、判断题卷只有 A/B 两个选项而答案写 C/D），则：

1. `ans` 置为 `null`（**不保留**那个越界字母）；
2. 写入 `ans_note = "原卷答案与选项不匹配"`；
3. 检索与组卷把它当作「无答案」处理（`paper.py` 默认过滤，`search.py` 输出 `ans_note` 原文）。

当前命中 15 条（含 5 条判断题），例如 `GK-2002-a-X036`（opts 为 A/B/C）、`HB-2011-ty-X014`（opts 为 A/B/D）。

**两条禁令**：

- **不得**把越界字母当成答案输出；
- **不得**为它编造"口径"解释（如"判断题按对/错给 A/D"、"选项被裁所以用 A/B"）。越界就是缺失，统一表述为**"该题答案缺失，见原卷"**。

**例外**：`fig=true` 的图选项题（全库 **271 条**，其中 249 条 `opts` 为空）不适用——它们的选项本身是图片，答案是原卷给出的字母，照常输出并提示看图。

### 5.2.1 `ans_note` 的来源

`ans_note` 是**答案不可用时唯一的说明文本**，输出时原样引用，不得改写。来源：

| 来源 | 取值 | 条数 | 触发条件 |
|---|---|---:|---|
| ① 答案越界 | `原卷答案与选项不匹配` | 15 | `ans ∉ opts.keys()`（`opts` 非空） |
| ② 申论答案不可用 | `答案无法可靠对齐，见本卷「参考答案原文」` / `原卷未提供可提取的参考答案` | 122 / 10 | 小题级对齐失败 / 原卷没有参考答案 |

合计 147 条带 `ans_note`（行测 15 + 申论 132），其余记录的 `ans_note` 为 `null`。v1.7 的「同题变体答案不一致，以主记录 X 为准」类文案（原 12 条 / 8 组）已随同组答案冲突清零而消失；若历史数据中仍见到，按它指的主记录取答案。

### 5.3 申论 `ans` 的定位：参考要点，不是答案

- `ans` 是**"参考要点提示"**，来自原卷解析的要点摘录；它脱离材料与分值，**不能直接当答案发布**。
- 引用检索结果（`--kw` / `--kaodian`）时，若命中申论题，**必须**回 `references/shenlun/<省>-<年>-<卷别>.md`，按回退顺序取：
  - 「三、参考答案（按小题）」里该小题有实质内容 → 按小题取；
  - 「三」里写「见本卷参考答案原文」（或该小题为空） → 必须从「四、参考答案原文」取，并注明"整卷参考答案原文，小题级对齐不可靠"；
  - 只有「四、参考答案原文」→ 同上；
  - 两者皆无 → "该题答案缺失，见原卷"。
- `ans` 为空或带 `ans_note`（含 `答案无法可靠对齐，见本卷「参考答案原文」`、`原卷未提供可提取的参考答案`）→ 一律按缺失处理：**有 `ans_note` 就原样引用该文案**，无 `ans_note` 则写 "该题答案缺失，见原卷"，**不得推测、不得用同卷其他小题顶替、不得用生成内容冒充原卷答案**。
- 申论答案本身是"采分点导向、非唯一标准答案"，输出时按要点分层并注明这一点。

### 5.4 题干清洗

去除页眉页脚（`第 X 页 共 Y 页`）、重复卷名；合并被字库拆开的选项标记（如 `B`+`.①③`→`B.①③`）。

### 5.5 选项顺序

多栏排版的原卷按字母还原为 A/B/C/D，不按视觉位置。

### 5.6 图表题与 `fig` 判定规则

图形推理、资料分析的图表本身是图片，文本层只有题干与答案；此类题 `fig=true`，题干标注"图形题，图见原卷"。**公式按材料自算**：原 PDF 的公式常抽取不全，解析里的残缺算式不可照搬。

**`fig=true` 的判定（v1.7 起统一降到最后一步做，不影响同题折叠）**：

1. 原卷该题标记了"需要图"（`need_figure`）；或题干整块抽取为空（只剩图片），此时补一句"本题题干为图形/公式…"并置 `fig=true`；
2. **图选项题修正**：`opts` 没有实质文字（全为空，或只有 `A/B/C/D` 占位）**且**命中任一条 ——
   - 题干去空白、标点、数字后**只剩 A–D 这类标签**（`A B C D`、`.`），说明题干也在图片层；
   - 题型是图形推理 / 科学推理，且 `opts` 只有占位（原卷四个选项就是图）；
   - 题型是图形推理 / 科学推理，且题干几乎没有文字（< 5 字，如「单选、」「判断。」）。

   命中即置 `fig=true` 并清空 `opts`（这些题原先被误标 `missing_opts`）。v1.7 共修正 **59 条**，全库 `fig=true` 达 **271 条**。
3. 题干有实质内容、只是 `opts` 整块没解析出来的图形题**不改** `fig`（它们大多已有配图，改判会连带影响折叠与难度口径），由 `img` 配图兜底。

### 5.7 题干完整性（`stem_flag`）

抽取后对每题做一次质量判定，**只标记不删题**，每题写单值 `stem_flag`（按优先级 `watermark > contaminated > short > missing_opts` 取第一个命中的），当前共 **136 条**：

| 取值 | 含义 | 判定 | 条数 |
|---|---|---|---:|
| `watermark` | 含广告水印 | 出现「本试卷由 / 粉笔 / 上岸 / 扫码 / 公众号 / QQ群」（"上岸"需带广告语境） | 0 |
| `contaminated` | 含邻题残句 | 题干以 `）`/`)` 开头，或混入上一题的题号 / 设问 | 0 |
| `short` | 题干过短 | 去空白后 < 12 字；数字推理 / 图形推理 / 科学推理 / 类比推理 / 带配图的题**不判**（数列、图形、类比题本来就短） | 136 |
| `missing_opts` | 选项残缺 | 题干 < 5 字且无选项、又不是配图题；或图形/科学推理的选项是碎片（平均长度 < 2 字） | 0 |

消费方式：`search.py` 在题目下方打印 `⚠ 题干可能不完整（原因）`（`short`→题干过短、`contaminated`→含邻题残句、`watermark`→含广告水印、`missing_opts`→选项残缺）；`paper.py` 默认排除这 136 条，`--allow-flagged` 放开。申论记录同样输出该字段，当前全部为 `null`。

### 5.8 同题重复与变体一致性

同一题会在国考三卷、跨年、联考各省重复出现。数据保留每条原始记录（便于按卷核对），用 `canonical` 标记主记录；检索默认只出主记录，`--all-variants` 展开。全库 1 091 条为同题变体（行测 11 393 → 折叠后 10 302）。

**折叠后做同组一致性校验**：含变体的组共 **1 021** 组，逐组对齐到主记录（`canonical == id`）：

1. **答案以主记录为准**：成员答案与主记录不同 → 成员的 `ans` 置 `null`，写 `ans_note` 指向主记录；主记录没有答案而成员有时，用成员的多数值回填主记录。当前 **0 组答案冲突**（v1.7 的 8 组已按原卷定案清零），行测有答案 **8 478**。
2. **元数据统一（现行规则，v1.7.1 起）**：`module/type` **不覆盖**——它们由各卷分节结构决定，同一道题在乡镇卷可能编进常识、在县级卷编进判断推理；同模块成员的 `code / sub / diff / theme`（及 `diff_raw`）对齐主记录；**分节不可信时**（该卷 `sec` 空行 > 50%）以 `code` 前缀回写 `module/type`，保证 `code ↔ module ↔ sub` 自洽。跨模块的 **6 组**保留各自一套口径。
3. 校验后各组只有**一套** `code/sub/diff/theme` 与一个有效答案（跨模块组按第 2 条各留一套），跨年份引用同一道题不会出现两套标注。

### 5.9 答案缺失

26 套卷（广东 2004–2021 行测、国考 2002 B 卷、国考 2021 副省级）的原始答案 PDF 无文字层（图片件），`ans` 为 `null` 且无 `ans_note`，共 **2 915 题（25.6%）**；输出时必须如实说明为"该题答案缺失，见原卷"，**不得编造答案**。逐卷数字见 `docs/coverage.md`。

## 六、复现与再生成

`tools/pipeline/` 保留了从原始 PDF 到本库的完整流水线（PyMuPDF 文本抽取 → 题目结构化 → 考点分类 → 索引与文档生成）。重新采集时：

```bash
python tools/pipeline/survey.py        # 先探测 PDF 文本层可用性
python tools/pipeline/build_xingce.py  # 行测抽取
python tools/pipeline/build_shenlun.py # 申论抽取
python tools/pipeline/finalize.py      # 生成 data/
python tools/pipeline/gen_docs.py      # 生成 references/
```

流水线不依赖公网，只依赖 `pymupdf`。

> 注：`references/00-index.md` 的「按考点检索」表由 `gen_docs.py` 生成，题量为**同题折叠后**口径，首次数据行上方有口径脚注；全量口径以 `docs/kaodian-taxonomy.md` 与 `scripts/search.py --list-kaodian` 为准。
