# 考点体系（完全对齐 gongkao-huasheng13）

本表是本库唯一的考点字典：题目标注、检索键、`references/kaodian/` 文件名均由此表派生。

**对齐原则**

1. 模块名、题型名、子题型名一律沿用 `gongkao-huasheng13` 的表述，不改写、不合并、不新增二级体系。
2. 体系未单列的旧题型（数字推理、科学推理）只做「模块级对齐 + 显式标注」，在表中标记为「体系外补充」。
3. 一个考点 = 一个 `code`；`code` 只用于检索与文件命名，展示时始终用中文题型名。

**编码规则**：`模块前缀-题型缩写`。ZL=资料分析，SL=数量关系，YY=言语理解，PD=判断推理，CS=常识判断，SN=申论。

**总题量**：11812 题（行测 11393 + 申论 419）；**三级子考点**：211 个标签（其中 51 个是题型兜底项，其余为可精确检索的细粒度子考点）

## 字段口径（v1.9）

`sub` 与 `form` 是两个正交维度，一个字段只承载一种含义：

| 字段 | 含义 | 取值 | 用法 |
|---|---|---|---|
| `sub` | **知识点**（考什么） | 见下方各模块的三级子考点表 | `search.py --sub 两期比重差` |
| `form` | **设问形态 / 空数**（怎么问） | `选正确项`、`选错误项`、`判断个数`、`排序与图示`、`一空`、`两空`、`三空及以上`、`null`（不适用） | 按形态筛选（如「两空」题） |

- 资料分析：「选正确项 / 选错误项 / 判断个数 / 排序与图示」只出现在综合分析题（`ZL-COMP`）；
  设问是「…是多少」的计算/读数题没有对应形态，`form` 为 `null`。
- 逻辑填空：`form` 记空数（一空 / 两空 / 三空及以上）。题干横线被 OCR 压成空格时，
  按解析「第N空」与选项词形推断，属推断值；知识点另由 `sub` 记（语境分析 / 实词 / 成语 / 虚词）。
- 兜底子考点统一命名「XX（待细分）」：图形推理、数字推理、逻辑判断、常识、申论判不出细分时
  一律落待细分，**不再落回「（综合）」**；「（综合）」只保留给真正的综合题（资料分析的「综合分析」题型、各题型的总结性考点）。
