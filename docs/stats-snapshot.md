## 口径要点

- **全量 vs 折叠后**：全量 = `data/*.jsonl` 的原始记录数（同一道题在国考三卷、跨年、联考各省重复出现时各算一条）；折叠后 = 同题只留主记录（`canonical == id`）。报题量必须二选一写明口径，同一段回答里不要混用。
- **答案三态**：`ans` 非空 → 直接给字母；`ans` 为空但有 `ans_note` → 原样引用；两者都无 → 「该题答案缺失，见原卷」。
- **子考点**：`sub` 字段的题量随数据修订与折叠策略变动；表内的 PD-TX 四类二级子考点是「`sub` 精确等于该标签」的计数。
- **评测**：`tests/eval.py` 的强标注集卡阈值（module 90% / code 80%），弱标注集只展示；准确率随题库演进会小幅波动，阈值是防回归下限。
